# Resumen

El presente ensayo describe el desarrollo y funcionamiento del proyecto Trivia del Mundial, un juego interactivo de preguntas y respuestas sobre la historia de las Copas del Mundo de fútbol, implementado en Python. El programa organiza 30 preguntas en tres niveles de dificultad, lleva un puntaje acumulativo y ofrece retroalimentación inmediata al usuario tras cada respuesta.
Palabras clave: Python, programación, lógica, juego interactivo, trivia, Copa del Mundo.

## Introducción

La programación permite construir soluciones a problemas concretos a través de la lógica y el código. Una forma efectiva de aprender sus fundamentos es mediante proyectos prácticos donde el resultado sea tangible. Con esa idea, el equipo desarrolló un juego de trivia sobre los Mundiales de Fútbol, combinando el interés por el deporte con la aplicación de
conceptos básicos de programación en Python. El programa corre directamente en la consola y no requiere instalaciones adicionales: el usuario simplemente elige entre cuatro opciones por pregunta y al final recibe su resultado.

# Descripción del Proyecto

El juego almacena sus 30 preguntas en un diccionario de Python dividido en tres categorías: Fácil, Medio y Difícil, con diez preguntas cada una. Cada pregunta contiene el enunciado, cuatro opciones, la respuesta correcta y un dato curioso que se muestra luego de responder. Las preguntas se mezclan aleatoriamente en cada partida, lo que hace que cada sesión sea diferente.




El programa valida que el usuario solo ingrese letras válidas (A, B, C o D) antes de aceptar la respuesta. Tras cada respuesta, indica si fue correcta o no, muestra el dato curioso y espera que el jugador presione Enter para continuar. Al terminar las tres categorías, calcula el porcentaje de aciertos y muestra un mensaje de desempeño: desde 'Eres un experto' (más del 90%) hasta 'El futbol no es lo tuyo' (menos del 30%).

# Técnica Aplicada: Desarrollo de Juegos en Python

La técnica utilizada es el desarrollo de juegos en Python, aplicando los recursos nativos del lenguaje para construir una experiencia interactiva desde cero. Se usaron diccionarios y listas para almacenar las preguntas, funciones para organizar cada parte del juego, bucles para recorrer las preguntas, condicionales para evaluar respuestas y el módulo random para mezclarlas en cada partida. Sin necesidad de librerías externas, Python permite construir un juego completamente funcional usando únicamente sus fundamentos básicos.
